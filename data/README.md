# Dataset Information

## 📊 Dataset

EmoLens uses **FER2013 facial expression images** together with the **official FERPlus annotations from Microsoft**.

The original FER2013 dataset provides the facial image pixel data, while FERPlus provides emotion annotations based on multiple human annotator votes for the same images.

For EmoLens, the FER2013 and FERPlus files were verified to contain **35,887 aligned rows** with matching `Usage` splits.

## 🎯 Selected Emotion Classes

EmoLens uses exactly five emotion classes:

* Angry
* Happy
* Neutral
* Sad
* Surprise

The following FERPlus categories are excluded:

* Disgust
* Fear
* Contempt
* Unknown
* NF

## 🏷️ Label Selection

FERPlus provides multiple annotator votes for each image.

For EmoLens, only the five selected emotion columns are considered:

```text
anger
happiness
sadness
surprise
neutral
```

An image receives a label only when:

1. One of the five selected emotions has the highest number of votes.
2. That highest vote is unique.
3. The highest vote count is greater than zero.

Images where two or more selected emotions have the same highest vote count are excluded because assigning one of those emotions would introduce an arbitrary label.

The original FER2013 `emotion` label is not used to override the FERPlus label.

## 🔄 Preprocessing

The preprocessing pipeline:

1. Loads `fer2013.csv`.
2. Loads the official `fer2013new.csv` annotations.
3. Verifies that both files contain the same number of rows.
4. Verifies that their `Usage` columns are aligned.
5. Applies the five-class FERPlus voting rule.
6. Removes ambiguous/tied labels.
7. Converts the FER2013 pixel strings into `48 × 48` grayscale PNG images.
8. Preserves the original FER2013 `Training`, `PublicTest`, and `PrivateTest` split assignments.

The preprocessing script is located at:

```text
src/preprocess_ferplus.py
```

The original dataset contains:


```text

```

## 📁 Dataset Storage

Dataset files are stored locally under:

```text
data/

├── raw/
│   ├── fer2013.csv
│   └── fer2013new.csv
│
└── processed/
    └── ferplus_5class/
        ├── train/
        ├── validation/
        └── test/
```

### `raw/`

Contains the original FER2013 CSV and official FERPlus annotation CSV.

### `processed/`

Contains the five-class dataset generated by the EmoLens preprocessing pipeline.

## 🔒 GitHub Policy

Dataset files are **not committed to the GitHub repository**.

The `.gitignore` file excludes:

```text
data/raw/
data/processed/
```

This prevents large dataset files from being uploaded and avoids redistributing dataset files without confirming the applicable terms.

## 📝 Dataset Sources

### FER2013

Original FER2013 facial expression dataset containing 48 × 48 grayscale facial images.

### FERPlus

Official Microsoft FERPlus annotations for FER2013.

The FERPlus repository and annotation files were obtained from Microsoft's official repository:

```text
https://github.com/microsoft/FERPlus
```

The applicable dataset licenses, terms of use, and access conditions should be reviewed from the original dataset sources before redistribution or other uses.

## ⚠️ Important Note

EmoLens is an educational and research-oriented facial expression recognition project.

Facial expression predictions are **not definitive measurements of a person's actual emotional or mental state**. The model may be affected by factors such as lighting, pose, image quality, facial appearance, dataset bias, and differences between training data and real-world images.

Model predictions should therefore be interpreted as **facial-expression classifications**, not as reliable conclusions about a person's internal emotional state.
